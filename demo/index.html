01. Foundations of Color

This project started with a simple goal: make color more accessible for everyone. I’ve been building this system since 2013, shaped by years of working on inclusive design challenges. At the center of it is @rgbyk/color — a core library that brings structure to color in a way that’s both thoughtful and flexible.

02. Color Theory in Practice

While it's deeply practical, the system is also grounded in theory—primarily the Munsell Color System. If you're familiar with Munsell, you'll notice a few thoughtful evolutions: an expanded hue set (12 instead of 10), more intuitive naming, and improved perceptual balance.

03. Designing for Perception

The framework analyzes color through a cylindrical model—evaluating hue, lightness, and saturation—then calibrates spacing using human visual response data. The aim is perceptual uniformity, not just numerical symmetry. And while it’s already finely tuned, nearly every parameter can be adjusted or extended as needed.

02. Value (Vertical Axis)

Value describes lightness, from black at the bottom ($value-0) to white at the top ($value-24). Grays lie along this axis and form the neutral middle range.
